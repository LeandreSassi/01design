One-click automation Grasshopper to Revit: Complex geometries

One-click push from grasshopper to revit (before rhino.inside era)

With the help of the plugin Hummingbird, Grasshopper models can be pushed automatically through a .csv file to Revit families using coordinates of the model points and generic families.

Grasshopper as modeling tool

The core idea of this project is to control a system that brings together urban, architectural and human scales. Grasshopper is used to program a fractal-based geometry that forms the main construction of the building.

The octagonal-looking hexagon (120deg) provides the base upon which we make a fractal grid.
The fractal grid is a perfect way to generate complex shapes with little information. Every iteration hold its own scale. This leads the architectural system.
By selecting the grid cells and adjusting the height, Grasshopper computes the whole structure that can be pushed to Revit in one click.
