01 Design full Python course

From beginner to advanced

The main goal of this course wat to teach Msc.2 graduation students at the TU Delfts Building Technology Master how to use Python to do some advanced Data Analysis and programming. In this course, everything is covered in order to be able to develop a full program. This course has been developped and written by me and Jamal Van Kastel.

In this course we cover in depth everything about Python and data science:

  • Programming: from procedural to functionnal and object oriented
  • Libraries: NumPy, Matplotlib, Pandas, Geopandas, Flask, OSMnx...
  • APIs: how to get geoJson realtime data
  • Data science: Statistical functions, machine learning etc...
