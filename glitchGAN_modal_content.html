Audioreactive latent interpolation pixel sorting.

Here, I forked JC Brouwer's audioreactive repo, updated it and added some functions to make it glitch using a self made pixel sorting algorithm.

This uses a StyleGAN model and produces noise based on a audiofile that will define how we move through the latent space created by the pretrained Nvidia HQfaces model. After this, we perform a pixel sorting on each frame to create this horrible effect.
